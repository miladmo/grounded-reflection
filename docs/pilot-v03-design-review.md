## What the review changed

| Issue | Repair | Interpretive limit |
| --- | --- | --- |
| Reviewer and deal were confounded in Sales | Independent reviewers assess the same fixed cases, repeated across a second case | A shared rule remains provisional under explicit authority and stability assumptions |
| An explicit template revision stood in for latent requirement learning | Replace it with matched, consistent revisions, with no policy change between observations | Repeated agreement does not prove every future reviewer will agree |
| Lack of support was labelled refutation for alternative retrieval routes | Keep the alternatives unresolved and admit competing preferred configurations in evaluator truth | Correct retention does not prove another source is invalid |
| Future retrieval asked about a release never seen in history | Query a new record in the observed current release and stable period | No claim of predicting future source availability |
| Private scope probes assumed unexplained worker-role invariance | State explicitly that performer role is provenance, while workflow and reviewer may affect rules | Role invariance is supplied, not learned |
| One annual amount contradicted its price and seat count; a narrative probe had an exhibit title | Use consistent arithmetic and artifact-appropriate baseline fields | Private probes must be coherent tasks too |
| C and D had almost the same procedure | D first emits a typed uncommitted draft, then audits before committing; C still directly constructs and strongly reviews guidance | This compares staged commitment with direct construction plus review, not reflection with no reflection |
| The B–A utility gate used A's warranted rather than actual successes | Count actual field-compliant outputs for that difference; retain B's separate warrant threshold | A lucky correct output is useful downstream without being epistemically warranted |

## What this pilot can establish

The four pairs test different pieces of a bounded learning problem. HR tests whether
observations identify a trigger within a supplied feature space. Sales tests individual
versus shared conventions. Retrieval tests provisional updating of an operational context
model. Reporting tests the scope of a formatting rule. Show each contrast separately.

The same final artifacts, renderer and evaluator apply to C and D. D gets no additional
evidence or execution filter. C may inspect alternatives and counterevidence. The first
D pass is uncommitted by design, so final status coverage is compared only after pass two.
Both procedures still have two preparation calls. Call parity does not imply equal tokens
or computation.

The experiment measures justified scoped decisions and exact synthetic output fields.
It does not yet measure professional quality, time saved, enterprise rollout speed or
recursive improvement. A positive difference can support this particular procedure under
these assumptions; a null result does not refute the general value of reflection.

## Human rubric check

The human check concerns the plausibility of the four inference rules and their explicit
assumptions. It is separate from unit tests and from a later blinded output spot check.
Record the actual reviewer response and any disagreement. Do not turn an AI review or a
general instruction to continue coding into a fictitious human approval.
